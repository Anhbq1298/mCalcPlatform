5 Not covered

  • Drops combined with openings, drops offset from the column, circular or rotated columns with a drop at a slab edge, and a drop that reaches an edge the column is set back from.
  • A drop that is under Fig. 6.17 in one direction and Fig. 6.18 in the other (l_H straddles 2h_H).
  • A verified link design around a rectangular column head with lH ≤ 2hH: the tool places and maps the links, but the result stays Not verified (see table above).

6 Input: total drop thickness and link arrangement

The drop is entered by its total thickness htot (slab plus drop); the projection below the slab is hH = htot − h and dH = d + hH. Designs saved with the older depth input open with htot = h + hH.

Provided links are entered as rows of n layers at spacing s: row 1 is measured from the column face, each later row adds n layers at its spacing. Every layer of a row has the same bar, shape and number of links. Auto arrangement runs the automatic design and writes it into the rows; consecutive layers with the same spacing merge into one row with the largest link count of those layers, so the arrangement never has fewer links than the design. With a drop, the arrangement runs straight across the drop edge: layers inside the drop belong to the section with dH, layers beyond it to the section around the drop with d.

7 Shear stress figure

The stress figure shows vEd along u0, u1 and uout,ef (or u1,ext for a drop). The mean value is VEd/(u·d). When β comes from moments at an internal column (Eq. 6.39, 6.42 or 6.43) the shape is the plastic distribution behind Eq. 6.39 (Fig. 6.19): a constant part plus k·M/W1 with the sign of the side, scaled so that the peak equals β times the mean. With the simplified or a user β, and at edge and corner columns, the figure shows the uniform envelope β·VEd/(u·d). The check itself always uses β·VEd/(u·d).
