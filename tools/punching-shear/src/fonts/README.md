# Drawing font

`osifont.ttf` is osifont (https://github.com/hikikomori82/osifont), file `osifont-lgpl3fe.ttf`,
licensed under the GNU LGPL version 3 with the GPL font exception. It follows ISO 3098 and is the
fallback for ISOCPEUR, which is used first when it is installed on the user's computer (ISOCPEUR
ships with AutoCAD and cannot be redistributed).
